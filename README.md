## Scopo del Repository

Questo spazio raccoglie tutti i programmi in Python, i lavori di laboratorio e le documentazioni realizzati durante l'anno scolastico. Lo scopo principale è tenere in ordine il codice e imparare a usare correttamente Git e GitHub per la gestione dei progetti informatici.

## Convenzione di Denominazione delle Cartelle

Per mantenere una struttura ordinata e facile da navigare, i nomi delle cartelle seguono una regola standard basata sui moduli didattici:

* `M0_...`: per la configurazione iniziale, gli strumenti di sviluppo e l'ambiente di lavoro.
* `M1_...`, `M2_...`, ecc.: per i moduli successivi dedicati ai vari argomenti e programmi in Python.

## Struttura del Progetto

Di seguito viene mostrato l'albero delle cartelle e dei file presenti nel repository:

```text
.

```

## Dove Trovare le Consegne

Tutti i compiti, le esercitazioni e i lavori pratici si trovano all'interno della cartella corrispondente al modulo di studio. Ad esempio, la documentazione relativa alla configurazione iniziale è salvata nella cartella `M0_ambiente/`.
